mend applies an edit that an AI model wrote to a tree of text files — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and text-editor JSON tool calls — matching lines at three tolerance tiers, and writing every change or none. Built to SPEC.md v1: 100/100 public practice checks, plus an 83-case spec-derived edge battery.

## Run it

```sh
node main.ts [--format=unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
